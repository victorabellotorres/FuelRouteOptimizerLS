##Proyecto de la assignatura IA de la UPC-FIB 2025/2026

Queremos distribuir un recurso(gasolina) entre diferentes localizaciones que necesitan reabastecimiento. Utilizaremos algoritmos de búsqueda local para ayudar a una compañía ficticia. Se nos presentará una situación de un día en concreto y deberemos de asignar que gasolineras se deben reabastecer para que puedan seguir funcionando y maximizar los beneficios. 

Cada mañana, a un camión cisterna le ha de llegar un conjunto de peticiones y esta las ha de servir haciendo unos viajes específicos. Esto es lo que queremos resolver con nuestros algoritmos de busqueda local utilizando AIMA.


Autores: Victor, Mario, Uri
